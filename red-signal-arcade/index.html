03 · Signal memory lab
Every event is stored as UTF-8 bytes and mapped into a deterministic, losslessly reversible binary waveform. Search uses byte-sequence matching, not semantic similarity. The visual wave is a preview, not the stored data.

04 · Bridge / experiment protocol
For Red running locally: copy the observation, pass it to Qwen, execute its returned action here, and feed the text response back. The game never tells Qwen what wins. A browser-only automatic agent is not included: this page does not directly call your laptop's llama.cpp server.
Suggested agent instruction
You are controlling an unfamiliar game. You receive only a JSON observation. Choose exactly one action. Respond with one line only: FLIP ONE, FLIP TWO, FLIP THREE, FLIP FOUR, FLIP FIVE, FLIP SIX, FLIP SEVEN, FLIP EIGHT, NEXT, or OBSERVE. Discover the game through feedback. Do not assume rules you have not observed.
Experiment controls
The browser stores game progression and memory in localStorage. Refresh preserves them. Reset game clears progression but not memory. For controlled comparisons, export memory before clearing it.
