CONTROL CONTRACT

Build 043 is paired to Build 042. It uses the same fifty world seeds, identical world generation, energy, movement, reproduction, mutation, recombination, population logic and RNG sequence. The single ecological change is MAX_AGE = Infinity. The age check remains in place, but no finite age can trigger it.

043 never imports an evolved 042/041 world state. Every longevity world starts clean at tick 0 so the pair remains identical until the moment the old 8,000-tick age rule would have mattered. The Build 042 survey ledger is read only as an observer reference, especially for worlds recorded extinct exactly at tick 8,000.

The longevity ledger additionally records founders versus descendants, the state at tick 8,000, oldest observed age, last birth tick and the first reproduction after tick 8,000. None of those measurements call RNG or feed back into the organisms.
Observer-only: camera rotation, field visibility, slice focus, lineage filtering, centroid calculations and seed selection never feed back into the volume. The organisms do not know they are being rendered.
