Can fading sensory traces teach temporal order?

Crash's sensory input

Two signals, composed from fading memory. Crash receives only RGB measurements, never ages.

Learning controls

Training feedback is one bit: prediction correct or incorrect. Evaluation never updates weights. Each trial uses a new randomly generated pair.

Experiment notes

Crash's learner sees only two sampled RGB triples from a 32×32 afterimage. It must choose which trace will disappear first. Ages and ground truth remain in the laboratory. Both points are the same original color and have different ages, so brightness is a valid cue in this controlled experiment. Success would demonstrate learning that cue, not a general understanding of time.
