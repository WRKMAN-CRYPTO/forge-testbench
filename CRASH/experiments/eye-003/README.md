# Eye 003: Temporal Discovery

Experimental, replaceable online learner. Each trial creates two equal-white point events at distinct ages in a 16-frame 32×32 RGB stack. The same afterimage compositor used by Eye 002 produces sensory values. The learner receives only the two RGB triples, not age, layer number, timestamps, or correct choice. It predicts which event is older and thus disappears first if the memory continues shifting. During training it optionally receives binary correctness feedback; its three logistic weights update by a simple online gradient rule. Evaluation consists of 200 fresh random trials without weight updates. Ground truth appears only in laboratory diagnostics, not learner inputs. This is a deliberately constrained test: because original colors are identical and signals are isolated, intensity correlates with age. Strong results support cue learning, not abstract time understanding. No training persistence across reloads; export JSON.
