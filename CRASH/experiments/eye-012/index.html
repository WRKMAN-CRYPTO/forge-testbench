Architecture

Each trial contains a persistent 4×4 colored target and multiple 4×4 transient colored distractors. Ten frames are accumulated at 10% each. The target determines binary A/B feedback, but the learner receives only the resulting 32×32 RGB memory.

A shared trainable attention scorer examines each of 64 spatial tiles. Its attention weights select a weighted combination of tile color signals, then a learned classifier predicts A/B. Both the attention scorer and classifier update from correctness feedback. The control learner sees only the global RGB totals.

The architecture supplies 4×4 tiles, local intensity features, an attention mechanism, and a supervised objective. Success would show learned spatial weighting under these constraints, not autonomous discovery of objects or attention itself. Evaluation does not update weights.
