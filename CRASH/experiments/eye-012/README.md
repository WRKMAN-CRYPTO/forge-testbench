# Eye 012: The Color Hunter

Independent experiment, leaving Eyes 008–011 unchanged. The environment creates a persistent 4×4 colored patch at a random 4×4-aligned tile and 2/5/9 colored distractor patches lasting 1–3 of ten frames. The displayed 32×32 RGB memory is the ten-frame 10%-per-frame sum. The hidden target patch's color family determines binary A/B feedback. Two learners start with zero weights: a spatial learner with shared trainable softmax attention over 64 tiles and a learned logistic head, and a control learner receiving global red-vs-green contrast only. Both receive identical training examples and outcome feedback. Attention training uses the gradient of logistic prediction loss through the softmax attention weighting. Evaluation freezes both learners. Held-out positions occupy lower half; training uses upper half. Novel shades vary target brightness. Target attention share is measured against chance 1/64 = 1.5625%.

**Caveats:** 4×4 tiling and local color contrast are engineered inductive biases; the target is always the longest-lived and most intense tile. This is supervised discriminative learning, not discovery of objecthood or general-purpose visual attention. The global control is intentionally weak, but may still exploit class-dependent total color. The UI should be tested in browser; GitHub commits alone do not establish runtime correctness.
