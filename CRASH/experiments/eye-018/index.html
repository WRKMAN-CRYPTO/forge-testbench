What can a pixel-only oracle infer?

The marker does not show a direction. We count how many colored candidates occupy any cardinal offset 1–3 from the marker. If there is more than one, the visible geometry alone does not uniquely specify which was secretly chosen. We also compare the target's distance against all competing candidate distances and report how often a naive nearest-candidate heuristic would be correct (ties split fairly).

These diagnostics cannot by themselves establish the optimal Bayesian classifier. To prove exact label ambiguity, we'd need counterfactual sampling probabilities for identical images under distinct hidden target choices. This is a targeted distribution audit, not a formal impossibility proof.
