What Crash is allowed to learn

Balanced red and green objects persist for ten frames. A white tile touches one object on a cardinal side. The correct A/B response depends on that object's color.

The fixed front end identifies colored 4×4 candidate tiles in the accumulated RGB image, then extracts raw RGB values from their four neighboring tiles. The trainable filter assigns separate weights to those four neighbors. It must learn which neighborhood cue deserves attention. The learner does not receive the target position, marker direction, or a precomputed “white marker above” feature.

This is not unrestricted pixel perception: candidate segmentation, 4×4 tiling, and four-direction sampling are supplied. The marker is always one tile away. Changing its direction at evaluation tests whether the learned filter is direction-specific. The global RGB control should remain near chance.
