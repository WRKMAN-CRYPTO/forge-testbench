# Eye 008: The Stranger in the Pixels

An isolated learnable pixel-attention experiment. Eight 32×32 grayscale frames contain one persistent target pixel at a randomized position and onset, plus 0, 3, or 9 random one-frame flashes per frame. The answer is which half contains the persistent signal. No coordinates, onset times, precomputed differences, or target labels enter the model's prediction. The fixed architecture has eight trainable temporal weights shared across all 1024 pixels. For each pixel, ReLU of the weighted raw intensity history is its attention score; left/right attention sums determine a stochastic logistic choice. Online binary feedback backpropagates through ReLU to update the shared weights. Last-frame brightness-sum baseline is frozen.

**Important limitations:** the 8-frame buffer, ReLU architecture, shared weights, left/right pooling, and loss/optimizer are designed in advance. The model learns which pixel histories matter, but does not create an attention architecture or discover an object concept. Attention maps display model activations, not explanations of conscious perception. Evaluate before training. For generalization, train 10k on upper rows, evaluate on lower rows without updating. Heavy flicker stress test. Export JSON results. All evaluation uses fresh trials and does not update weights.
