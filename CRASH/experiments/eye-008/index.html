What is supplied?

The world contains one persistent target pixel, randomly placed on the left or right, plus unrelated one-frame flashes. Crash receives all eight complete 32×32 grayscale images. A trainable, position-shared eight-frame filter produces a score for each pixel. Those scores form the attention map and are pooled into left/right evidence for the answer.

The eight filter weights are learned from binary correctness feedback. There is no precomputed change map, hardcoded target position, or explicit onset extraction. The fixed frame buffer, filter structure, left/right pooling, and training algorithm are still supplied equipment. Attention is a learned relevance score, not proof of object recognition.

For a fair location-generalization test, train with Training positions selected, then evaluate Held-out positions without retraining. The last-frame baseline sums brightness in each half and never learns.
