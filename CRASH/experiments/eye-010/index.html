What this tests

Each of ten incoming RGB frames contributes 10% to a fresh black canvas in each channel. RGB and red/green/blue accumulate separately; grayscale is computed from the incoming RGB brightness. The channels are never merged for learning or decision-making.

Equal-brightness red and green should be hard to distinguish in grayscale but clear in separate channels. Stationary recoloring can preserve location while shifting which channels brighten. A ten-frame sum loses temporal order, so it cannot by itself tell which color came first.
