# Eye 013: The Camouflage Test

Two or more red/green object pairs persist for ten frames. A white marker sits one 4×4 tile directly above one target object; binary feedback depends on that object's color. The entire scene is compressed into a 32×32 RGB ten-frame 10%-additive memory. Each trial has balanced counts of red and green objects and the same per-color intensities regardless of which color is marked. Thus the global RGB totals contain no label information (barring implementation bugs).

The **supplied** perception front end segments aligned 4×4 colored candidate regions and computes each candidate's red/green signal and the minimum RGB intensity of its tile directly above. A softmax attention model learns the importance of that above-neighbor cue from binary feedback, while a logistic head learns the association of attended color with A/B. A global color-only logistic learner is a negative control. The attention head starts at a small positive weight (0.1) to break a zero-gradient symmetry, not as a learned color mapping. The marker meaning, target position, and class are not passed into the predictor. The candidate extraction and spatial relationship are *engineered*, not discovered.

Training uses target positions in upper rows 1–3; held-out positions use lower rows 4–7. Novel brightness affects both color families identically. Distractors come in balanced pairs, all persistent and equally bright. Chance attention share is 1/(2+2*pairs), not 1/64, because the candidate front end filters blank tiles. Evaluation freezes all weights. This is a controlled relational cue-learning experiment, not autonomous object recognition.
