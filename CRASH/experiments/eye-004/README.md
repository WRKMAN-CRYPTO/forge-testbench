# Eye 004: Brightness Trap (revised)

Eye 003 remains untouched. The first Eye 004 version used older ages 8–13. After RGB bit-shifting and opacity, those traces were often zero, making genuine brightness reversals nearly impossible. This revision uses ages 0–2 versus 1–4 for randomized conditions. Original grayscale brightness can be varied from 1 to 255 via UI controls. Equal-brightness baseline retains Eye 003's age ranges.

Modes: equal original brightness, random original brightness, or forced reversed brightness cues (up to 500 candidate attempts per trial). A *reversal* means the dimmer composite signal is actually the newer event, so a dimmer-means-older rule fails. The evaluation reports reversal rate and counts ties in exported JSON. If forced generation cannot produce a reversal, the exported count exposes that rather than claiming it succeeded. Ground truth and original brightness are not passed to the learner.

Import Eye 003 JSON or the previous Eye 004 export. First evaluate in equal mode, then random, then forced reversal without training between conditions. Use 1,000 evaluation trials per condition. The learner receives only two RGB triples and may receive correctness feedback during training; evaluation does not update weights. The brightness range and condition are exported with results. Strong results in this experiment would still not establish an abstract concept of time.
