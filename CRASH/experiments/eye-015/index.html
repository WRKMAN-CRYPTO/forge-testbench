Experimental boundary

Ten colored objects (five red, five green) persist. A white marker lies one, two, or three 4×4 tiles away from the selected object in one cardinal direction. In crowded scenes, other colored objects can be closer to the marker than the true target.

The fixed visual front end identifies colored candidates and samples white intensity at twelve possible offsets (four directions × three distances). Crash learns a separate weight for each offset and uses those weights to attend to candidate colors. No target location or distance is passed into the predictor.

Crucial limitation: The scene does not intrinsically identify which object a distant marker refers to when several objects share its row or column. A deterministic placement rule makes the target the only object on the marker's chosen ray within three tiles. This is an engineered, solvable geometry task, not unconstrained visual reference resolution. Candidate extraction and the offset bank are also supplied.
