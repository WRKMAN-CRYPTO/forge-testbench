What Crash can see

Each trial contains eight ordered 32×32 RGB frames. Two points appear at different moments and persist. Their original brightness is randomized. The sequence learner receives only the two pixel intensities in each frame, in order. It is never given onset times or which point is older.

The snapshot learner receives only the two intensities in the last frame. Both models use the same online logistic learning rule and correctness feedback. The experiment compares their held-out accuracy without updating weights.

The sequence learner is given an ordered buffer by design, so this tests learning from temporal observations, not independently inventing memory or time. Event onset can be recovered from these frames, unlike the deliberately ambiguous single composite in Eye 004.
