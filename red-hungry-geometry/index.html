🦴 RED // HUNGRY GEOMETRY

Memories become agents. Each creature discovers part of an unlabeled shape, carries its own circles, hunts geometrically similar creatures, and can consume and mutate. A separate control population never consumes. No OCR, alphabet, labels, or desired shape are supplied to the agents.

Tap the image to select a region. The yellow box identifies where creatures begin exploring. It is a selection aid only, not an identity label. Uploaded images are resized for the experiment. Discovery is randomized and bounded; creatures inherit circles and confidence counts rather than being given a correct silhouette.
