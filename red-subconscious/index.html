How this little mind works

Every word gets an agent. Considering a thought creates or reactivates its word agents. An experience creates a directed association from each cue word to each result word.

Agents compare their outgoing memories. If different cues repeatedly lead to the same result, their pathways fuse into a joint memory. The words themselves stay separate. This is a small associative algorithm, not an LLM or conscious subconscious.

Probes are read-only. Words in the question activate paths. The panel reports stored associations, the cue that triggered them and whether a fused pathway supported them. It will never fabricate a memory when there's no stored link.

Red bridge, for later: The page exposes window.RedMemory.learn("ONE","STAR"), window.RedMemory.consider("SEVEN"), window.RedMemory.probe("SEVEN"), and window.RedMemory.export() to scripts in this browser. This is a laboratory bridge, not a connection to Red's Linux desktop yet. JSON export/import can be used to move a memory snapshot.

No accounts, server, AI API, or external dependencies. Memory is stored locally in this browser. Reset clears it.
