RED // Experience Engine v0.3: Caveman


Every word receives a lightweight agent. Every recorded observation, action, or result becomes an experience agent. The engine finds repeated transitions and shared destinations. Agents do not need to know what a browser, game, or file is.


Probing finds prior experiences using weighted word overlap. Predictions are ranked by similarity and past supporting transitions. Competing outcomes remain visible. The confidence numbers are heuristic, not calibrated probabilities.


Surprise is raised when a next event disagrees sufficiently with a previously reinforced prediction. Surprise doesn't prove causation: it is a cue to pay attention.


Spontaneous echoes can surface when the newly recorded experience strongly resembles one from an older episode. The original evidence is preserved.


New episode cuts the chronological link so the engine doesn't silently associate the end of one task with the beginning of another.


Caveman: A deterministic, lightweight normalization pass drops many filler words, reduces some English word forms, preserves negation and uncertainty markers, and shows a clause-order arrow when BEFORE, AFTER, or THEN explicitly indicate sequence. Toggle ORIGINAL to restore all original word-agent indexing without altering source events. Compare both modes on exactly the same stored experiences.
Limits: This is a prototype using statistical word overlap, not semantic comprehension, causal inference, or autonomous desktop perception. The browser does not connect to Red's computer. All local data stays in this browser unless exported.


Script interface: window.RedMemoryV2.observe({type:"ACT",text:"press key"}), .startEpisode(), .predict(text), .recall(text), .export(), .runTests().
