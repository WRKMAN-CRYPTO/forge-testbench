EXPERIMENT RULES

Red is not told which build is best. The learner weighs previous outcomes against curiosity. He can repeat a successful build, revisit a failed one, or try a new combination. The combatant's body resets after death; Red's memories persist.

This is a separate training chamber using Soul Crucible's seven archetype stat templates and eight action names, with a simplified duel engine. It does not change the original Soul Crucible or its saves. Browser memory stays on this device. Red's browser subconscious is an experience journal; a separate general-purpose reinforcement scorer selects builds. This is not the Python instinct database.
