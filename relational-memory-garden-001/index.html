Rules: Agents have no stored stimulus labels. Coactivation strengthens pairwise relationships. Each agent's outgoing connection strengths share a fixed budget. Inactive links decay. A partial cue spreads activity through the network for three rounds.

Measurement: F1 compares recalled agents against the full target pattern, excluding directly cued agents. Scores are diagnostic, not proof of understanding.
