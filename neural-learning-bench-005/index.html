What counts as learning?

The circuits predict the next signal before seeing it. Only afterward do we adjust weights using the actual outcome.

The reactive circuit receives the latest signal. The memory circuit receives that signal plus the previous one.

Important: Alternation can be solved using the current signal alone. The AABB pattern is included because it requires knowledge of the previous signal. A random stream should stay near 50%.

This is a diagnostic of simple trainable circuits, not a demonstration that the evolving Wilderness architecture can learn. A positive result would establish a mechanism to transplant and test.
