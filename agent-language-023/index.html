VOCABULARY

RAW BRAIN




Build 023 begins from a clean brain. The learner trains on only 48 of 64 six-bit states. The 16 locked states are the cases where the first bit of all three input pairs matches: σ0 = σ2 = σ4. Every local pair pattern still appears during training, but those global combinations never do. The target law is compositional: output bit 0 = σ0 XOR σ1, bit 1 = σ2 XOR σ3, bit 2 = σ4 XOR σ5. Holdout states are evaluation-only: no reward, history, births, lexical competition, or causal vision may inspect them.
