RAW REPORT




Build 018 uses common random numbers rather than two free-running RNG streams. For a given seed and round, both universes receive the same state draw, the same token-choice draw at each position, and the same output draw. Randomness is keyed by seed + round + event, so a divergence in one universe does not desynchronize future rounds. Both twins begin as deep copies of the same frozen Build 016 checkpoint. The NORMAL twin permits A27→A31 lexical-competition pressure; the GLASS-WALL twin blocks only the direct A31↔A27 pair while leaving ordinary reward, selector learning, core learning, causal vision, and all other lexical competition active.
