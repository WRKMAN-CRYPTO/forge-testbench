WHAT IS BEING SOLVED?

At the first token, hidden state = 0. Every token score is therefore an affine plane over σ0…σ5. For each token Aᵢ, Build 025 solves:

maximize m
Aᵢ(x) − Aⱼ(x) ≥ m for every competitor j
−1 ≤ σd ≤ +1

A positive optimum means the word owns a real 6D volume. Zero means it can only tie on a boundary. Negative means another word beats it everywhere.
