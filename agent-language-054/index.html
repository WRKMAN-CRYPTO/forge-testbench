MESSAGE CENSUS

No completed messages yet.
A message is one uninterrupted run of P8 emissions from one speaker. The next non-P8 primitive, or that speaker's death, closes the message. Matching is exact bit-for-bit: a new string gets a new row; an identical string increments its count. Long strings are abbreviated only on screen; the exact string remains the identity key. This census is observer-only and cannot affect the world.

RAW ONE-WAY OUTPUT

No emissions yet.
P8 emits the agent's current 0/1 bit. The terminal is outside the world: agents cannot read it, emissions change no world cell, and no reward or response is sent back. Streams remain grouped by speaker so interleaved agents do not masquerade as one message.

WORLD LATTICE CONTRACT

A world is G2 + numeric seed. G2 always regenerates the same canonical 16×16×16 habitat for the same seed. Placement adds one of 24 orientation-preserving cube rotations. Rotation never changes the underlying world identity.

Missing blocks are true void: agents cannot move or be born into them. Present blocks contain traversable empty cells plus deterministic α/β/γ/δ fields. Adjacent present blocks have open seams. Birth remains capped at 180 living agents per destination block; migration is not capped.

Each agent carries observer-only birthBlock metadata: the block index where that individual was born. It never affects movement, energy, reproduction, mutation, selection or world state. Current-block color is a control view; birth-block color is a permanent historical stamp.

Build 053 adds P8 EMIT. Founders are still generated from the original P0–P7 alphabet, preserving the same founder programs for the same founder seed. P8 can appear only through a small additional mutation path. EMIT copies the agent's current bit into an external observer log; the agent cannot read that log and the world receives nothing back.

Build 054 adds only an observer-side message census. Consecutive P8 emissions by one speaker remain one open message until that speaker executes any non-P8 primitive or dies. The completed exact bitstring is used as the key: first occurrence creates a row, later identical occurrences increment it. Message counting never changes agent state, world state, reward, mutation, selection or reproduction.

The founder RNG is separate from habitat RNG. The share code stores lattice dimensions, every block seed/rotation/presence state, spawn block and founder seed. Build 054 can load Build 051/052/053 lattice share codes to recreate the same starting experiment.
