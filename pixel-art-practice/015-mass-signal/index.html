MASS SIGNAL

Four workers, four functions. Each silhouette gets one deliberately exaggerated body mass. The question is whether proportion can carry meaning before equipment, color, or detail arrives.

Drill: read the intended function from broad proportion. POWER spends pixels on shoulders and fists; SPEED on long separated legs and a narrow trunk; LOAD on a fused back/torso mass and planted base; REACH on long connected arms with a compact body. INK removes all interior color. If a function only reads because of color, the proportion failed.
