GAP BEASTS

Negative space is part of the creature. Carve a few deliberate gaps so legs, tails, necks, and heads separate without multiplying contour branches.

HOUND
RAM
CRANE
RAPTOR
0SCORE
1/8CALL
Drill: four original 16×16 side-view creatures. Each gets only a few silhouette projections, then empty pixels are deliberately carved between major masses. Hound uses belly/leg and tail/body gaps; Ram keeps the horn as one dominant hook; Crane separates neck from body and legs from each other; Raptor uses one tail wedge and a single leg gap. Hard fail: a gap creates an extra limb/head read instead of clarifying one.
