ANCHOR DROP

Four original 16×16 silhouettes spend their pixel budget on one or two diagnostic contour landmarks. Catch only the named object while silhouettes are moving. Toggle ANCHORS OFF to remove those identity-bearing features and feel what collapses.

Drill: KEY gets bow + teeth, BOOT gets toe + heel, FISH gets tail + nose break, CAN gets handle + spout. These are not decorative details: they are contour anchors. With anchors off, each form is intentionally reduced toward a generic mass. Hard fail: recognition depends on interior color or on studying the sprite while stationary.
